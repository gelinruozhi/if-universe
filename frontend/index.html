❓ 使用指南

🚀 快速开始

1. 在首页输入框中，以"如果..."开头描述你想探索的选择

2. 点击"开始探索"或按回车键

3. 等待 AI 生成你的平行宇宙故事

4. 在结果页可以查看故事、碎片和信笺

💡 输入示例

点击下方例子直接开始探索：

🎹 如果当年我没有放弃学钢琴
✈️ 如果我选择了出国留学
💌 如果我当初和ta在一起了
💪 如果我坚持了健身习惯
💼 如果我选择了另一份工作
✍️ 如果我早一点开始写作
🎮 功能介绍

⚙ 命运转盘 - 随机给你一个有趣的"如果"命题

🔄 平行对比 - 同时探索两个选择，对比不同结果

💨 宇宙碰撞 - 让两个已探索的宇宙融合碰撞

⭐ 我的收藏 - 收藏喜欢的宇宙随时回顾

🌐 探索广场 - 查看其他探索者分享的宇宙

🌟 今日运势 - 每天抽取一张宇宙运势卡

📚 宇宙年鉴 - 你的年度探索报告

⌨️ 快捷键

Enter 输入框中按回车直接开始探索

Ctrl + K 快速聚焦输入框

Ctrl + R 随机探索

Esc 关闭弹窗/取消探索

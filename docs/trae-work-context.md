## 一、项目概述

- **产品名称**：如果宇宙
- **产品定位**：AI平行人生探索应用（纯前端单页应用）
- **核心功能**：用户输入一个人生选择（如"如果当年我没有离开家乡"），应用生成三个维度的平行宇宙内容
- **技术栈**：纯前端 HTML/CSS/JS，零外部依赖，单一HTML文件
- **竞赛**：TRAE AI创造力大赛（2026年6月16日-8月22日）
- **赛道**：生活娱乐赛道
- **竞赛官网**：https://www.trae.cn/ai-creativity
- **赛事细则（飞书）**：https://bytedance.larkoffice.com/wiki/DScwwZPzsikvNzk5slJc2kgpnie
- **报名指南（社区）**：https://forum.trae.cn/t/topic/22548

## 五、功能模块（最新版 index-expanded.html）

### 5.1 页面结构（8个页面/弹窗）

1. **首页**：品牌标题 + 输入框（单行input，字符计数器0/100，底部渐变进度条）+ "开始探索"按钮（光扫效果）+ 推荐话题芯片 + 探索记录（localStorage，单条删除，相对时间）+ 底部快捷入口（命运转盘/宇宙图鉴/探索者档案）
2. **生成中**：三层嵌套星系旋转（18s周期）+ SVG环形进度条 + 加载文案轮播（7条）
3. **结果页**：宇宙编号（随机4位数）+ 三Tab（故事/碎片/信笺）+ 底部按钮（重新探索/分享/收藏）
4. **分享弹窗**：星空纹理卡片 + 标题/摘要/标签
5. **命运转盘**：SVG六扇区转盘（爱情/事业/财富/健康/旅行/学习）+ 旋转动画 + 随机命运描述
6. **宇宙图鉴**：网格展示已探索宇宙 + 点击重新查看
7. **探索者档案**：统计面板（总探索/收藏/连续天数）+ 8个成就徽章
8. **每日推荐弹窗**：每日推荐一个主题

### 5.2 结果页三Tab详情

- **故事**：时间线（紫→蓝渐变）+ 脉冲涟漪 + 打字机逐字显示
- **碎片**：Polaroid风格卡片（白色边框，微旋转，hover浮起，large/small交替）
- **信笺**：横线背景 + 红色圆形印章 + 墨水晕染（text-shadow）

### 5.3 游戏化系统

- **成就徽章（8个）**：初次探索、宇宙收藏家、命运之子、时空旅人、平行专家、深夜哲学家、分享达人、全知全能
- **数据持久化（localStorage键）**：
  - `yuzhou_history`：探索记录
  - `yuzhou_favorites`：收藏宇宙
  - `yuzhou_achievements`：成就状态
  - `yuzhou_stats`：统计数据
  - `yuzhou_lastExplore`：最后探索日期

### 5.4 技术特效

- Canvas星空（移动端70颗/桌面120颗，闪烁+色相偏移）
- 星座连线（3条随机）
- 流星（含反向流星）
- 三层星云（紫/蓝/青绿，漂移旋转）
- 鼠标跟随紫色光晕
- 入场动画序列（依次淡入）
- Web Audio API（三角波点击音 + 60Hz环境低频）
- prefers-reduced-motion支持
- 响应式（375px移动端适配）
- 键盘快捷键（Enter提交/Esc关闭弹窗）
- Toast通知（替代alert）

- 副文案：白色、轻字重(300)、较小字号

### 第二轮优化（18项）

## 九、用户偏好与设计原则

1. **标题必须分层**：品牌名大标题 + 分隔线 + 副文案，不要一大坨文字
2. **不要粉色**：品牌名用淡紫→淡蓝，不走粉色
3. **Tab文字简洁**：用"故事/碎片/信笺"，不用"平行故事/生活碎片/时空信笺"
4. **输入框用单行input**：不用textarea
5. **保留旧文件**：每次修改新建文件，不覆盖原有版本
6. **用户语言**：中文
7. **设计风格偏好**：沉浸感、视觉冲击力、宇宙浪漫感
